# Customer Financial Behavior Dashboard (Tableau)

## Overview
This project features an interactive Tableau dashboard analyzing customer financial behavior using a banking dataset. The dashboard focuses on trends in account balances over time and how offer acceptance varies across income levels. The goal of the project is to translate raw financial data into clear, decision-relevant insights using effective data visualization techniques.

The dataset includes customer balance information by quarter, income categories, and offer response indicators. Tableau was used to clean, reshape, and visualize the data in a way that highlights meaningful patterns and comparisons.

---

## Dashboard Components

### Average Balance by Quarter
A line chart displays the average customer account balance across four quarters (Q1–Q4). The quarterly balance fields were reshaped within Tableau to allow for time-based comparison. The visualization highlights seasonal changes in balances and provides a clear view of how average balances trend throughout the year.

### Offer Accepted by Income Level
This view examines offer acceptance rates across different income levels. By grouping customers into income categories, the chart makes it easy to compare how responsiveness to offers varies by income. The visualization helps identify which income groups are most likely to accept offers, supporting more targeted decision-making.
